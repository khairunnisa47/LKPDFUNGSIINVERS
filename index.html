🔍 Pertanyaan 4: Kapan Fungsi Memiliki Invers?

Mari kita selidiki syarat-syarat agar suatu fungsi memiliki invers!

A. Fungsi Satu-satu (Injektif)

Perhatikan contoh berikut:

✓ Fungsi f(x) = 4x (Donat)

• f(1) = 4000 → 1 donat = Rp4.000

• f(2) = 8000 → 2 donat = Rp8.000

• f(3) = 12000 → 3 donat = Rp12.000

Setiap jumlah donat menghasilkan harga yang berbeda!

✗ Fungsi g(x) = x²

• g(-2) = 4

• g(2) = 4

• g(-3) = 9

• g(3) = 9

Dua input berbeda menghasilkan output yang sama!

Diskusikan: Apa yang dimaksud fungsi satu-satu?

B. Fungsi Onto (Surjektif)

Perhatikan domain dan kodomain:

✓ f: ℝ → ℝ, f(x) = 2x + 1

• Untuk y = 5, ada x = 2

• Untuk y = -3, ada x = -2

• Untuk y = 0, ada x = -0.5

Setiap bilangan real bisa dicapai!

✗ h: ℝ → ℝ, h(x) = x²

• Untuk y = 4, ada x = ±2

• Untuk y = 9, ada x = ±3

• Untuk y = -1, tidak ada x ∈ ℝ

Bilangan negatif tidak bisa dicapai!

Diskusikan: Apa yang dimaksud fungsi onto?

📋 Kesimpulan: Langkah-langkah Mencari Fungsi Invers

Berdasarkan contoh di atas, berikut adalah langkah umum untuk mencari fungsi invers:

1

Ubah notasi $f(x)$ menjadi $y$

2

Tukar posisi $x$ dan $y$

3

Selesaikan untuk mendapatkan $y$

4

Tulis sebagai $f^{-1}(x) = y$
